# 杭州居民年度阶梯实施计划

用户在提供杭州资料后要求继续，沿用已授权的查漏补缺工作，原工作区增量实施。使用 writing-plans 整理、executing-plans 在当前任务执行，不重复申请已授权功能的确认，不提交已有未提交内容。

目标：可选择杭州居民地区方案，按独立结算户共享年度额度，污水费按量计算，并保存账单快照。资料核对见 `docs/hangzhou-water-policy-notes.md`。

设计选择：只替换 YAML 无法解决年度累计；按登录用户累计会误合并多地址；采用显式结算户绑定同一用户的一组水表。三种不可变预置版本为市区、余杭普通地区、西部四镇；管理员核对适用范围后选用。商业/工业继续保留标注的演示算法，超定额基价和个户额度尚缺，不编造。

数据：新增结算户、绑定表、年度余额、账单计价快照、每表计费锁。结算户保存方案、生效日、期初年度累计用量和依据。绑定不能覆盖已有同生效期账单；已有结算户不允许无审计改绑定或改价。每表锁协调绑定与出账，结算户行锁保护多表共同额度；出账失败必须回滚额度和快照，重复出账不再占额度。

年度：按读数时间的年度管理；已存在上一年读数且本次区间跨年时，必须先有上一年末23:59:59的分界读数，否则拒绝自动归属而不是估算拆量。历史迟到记录不得倒序插入已结算时序；有效期前未出账读数需先处理，不能静默切回示例水价。首年录入期初用量，后续完整新年额度从0开始。期初来源、边界限制在页面说明。

计价：供水阶梯216/300、1.90/2.85/5.70；污水单位价1.00/0.95/0.65。使用累计费用差额并在累计端四舍五入，确保多次计价之和等于合并计价；分档数量与金额进入快照，数值使用 BigDecimal。
