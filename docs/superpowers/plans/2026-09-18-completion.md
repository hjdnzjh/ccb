# 剩余业务能力实施计划

> 使用 subagent-driven-development 将独立子系统分配给专门实施者，主任务负责权限、接口集成和最终验收；按需求与代码两层检查。用户已明确授权继续完成，不重复要求审批。当前工作区已有上一阶段未提交改动，保留并继续开发。

**Goal:** 完成权限与用户端、持久化采集和补抄、可配置违约金、真实智能报表与导出。

**Architecture:** Java/MySQL 保存身份与业务状态；Vue 按角色路由；业务后端保护智能体代理；按子模块增量迁移。任务以数据库锁与唯一键实现重试幂等，复用已完成账务服务。

**Tech Stack:** Spring Boot 3.2、MyBatis/JdbcTemplate、MySQL 8、Vue 3、JUnit/MockMvc、浏览器验收。

**验收状态（2026-09-18）：** 本计划各项已实现。55 项 Java 测试（28 项实际 MySQL 集成）、9 项前端测试和 2 项 Flask 网关鉴权测试通过，前后端构建通过。所有测试与浏览器数据均与原业务记录隔离。
