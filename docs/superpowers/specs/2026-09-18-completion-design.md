# 权限、用户端、自动调度、违约金与智能报表

用户于 2026-09-18 明确要求继续完成四项后续能力，沿用已确认的赛题分阶段方案。本轮在现有工作区增量实现，不覆盖上一轮账务改动。

## 选择与边界

采用现有 Spring Boot/MySQL 的事务和持久化任务、Vue 页面及确定性指令解析；这能复用账务一致性并在离线比赛环境复现。外部工作流引擎或在线大模型会增加部署和密钥依赖，本轮不引入。模拟设备明确标注；不冒充实际远程设备或真实支付机构。

## 身份与用户端

数据库角色 admin/user 与价格类型分离。密码使用带盐哈希，历史明文仅在正确登录后升级，不再保留 admin 密码绕过。服务端存储随机令牌的摘要，8 小时有效，可退出撤销；每次请求校验账号状态。所有业务 API 默认管理员，/me 下接口仅从会话取当前用户，并在取账单、流水、付款、反馈时验证归属。拒绝匿名 401、越权 403。用户可查看自己的水表、用量、账单、缴费和到期提醒，提交异常反馈并查看管理员回复。前端按真实角色进入不同工作台，失效会话返回登录。智能体代理也必须经过业务后端鉴权。

## 调度与违约金

管理员可创建、启停、手动触发采集计划；计划及每次执行、每表重试落库，服务重启不会丢失。七字段设备报文进行格式、时间、累计读数校验与去重；成功采集保存审核通过的读数并幂等出账，故障数据记录可复现异常。模拟首次失败场景验证自动补抄，最大重试后留有失败记录。并发调度用数据库锁和唯一业务标识防重入。

违约金配置包括启用、宽限期、日费率和封顶比例；按账单与日期唯一登记，重复运行不重复计费，已结清不继续计费。不回溯升级前日期，付款和违约金共用账单行锁；规则、起算日和计费口径在界面/文档明确。

## 智能报表

管理员以结构化范围或中文指令选择日/周/月/年统计；解析不明的指令拒绝，不静默编造参数。数据来自已确认抄表、真实账单收款及异常记录；显示用水量、收入和设备故障率的分子分母及日期口径。报表生成快照后页面、XLSX、PDF使用同一数据，支持无数据范围和中文文本。只允许管理员访问，导出不执行用户提供的 SQL 或表达式。

## 验收

两普通用户互不能查询/支付对方账单，不能调用管理接口；退出和禁用账号立即失效。完整运行采集、首次失败补抄、去重出账及重复执行违约金测试。用 SQL/固定数据复核报表各粒度与边界，实际下载打开 XLSX/PDF。执行上一轮账务回归、前端构建及浏览器端到端操作。所有迁移可重复运行，保留既有演示数据，更新启动和验收文档。
